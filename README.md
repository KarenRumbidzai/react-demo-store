# React Demo Store

A self-built React e-commerce demo showcasing a complete customer journey — from product discovery to cart, login, and checkout. Built from scratch, without AI assistance, to demonstrate practical React fundamentals: reusable components, routing, state management, and responsive UI development.

## Features

- Product listing and discovery
- Add-to-cart and cart management
- Login / authentication flow
- 💳 Checkout process (no payment gateway integration)
- 📱 Fully responsive UI

## Tech Stack

- **React** — component-driven UI
- **Vite** — build tooling and dev server
- **Tailwind CSS** — utility-first styling
- **DaisyUI** — component theming (`winter` / `dracula` themes)
- **@tailwindcss/typography** — rich-text styling

## Why This Project

This demo was built entirely by hand — no AI-generated code — to practically demonstrate core React skills: componentization, client-side routing, state management across a multi-step flow (browse > cart > login > checkout), and responsive design with a utility-first CSS approach.
